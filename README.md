## ✨ Core Features

### 🎓 Candidate (Student) Portal
* **Synchronized Exam Taking**: Stateful assessment player with server-anchored countdown timers and answer key masking to prevent client-side inspection.
* **In-Flight Auto-Save**: Non-blocking background synchronization (`/api/v1/tests/{id}/autosave`) caches answers on every question selection, safeguarding against network dropouts.
* **Practice Drills**: Self-paced curricular quizzes across 6 tracks: Java, Python, ASP.NET, Aptitude, DBMS, and Cloud Computing.
* **Session Integrity Safeguards**: Detects window blur and tab switching, warns candidates, and triggers auto-submission after 5 infractions.
* **Instant Scorecard & PDF Export**: Automated grading upon submission, performance percentage, and client-compiled PDF scorecard downloads.
* **Question-by-Question Review**: In-depth explanations, correct answer rationales, and mistake filtering.

### 🛡️ Faculty (Admin) Console
* **Assessment Authoring Studio**: 4-step wizard to build tests: discipline selection, protocol mode (`MAIN` or `PRACTICE`), duration, question quotas, and passing criteria.
* **Central Question Bank**: 300+ curricular items across 6 tracks with instant search, category filters, and pagination.
* **Cohort Leaderboards**: Live merit rankings with Gold, Silver, and Bronze podium medals.
* **System Telemetry**: Real-time overview of active candidates, total assessments, and question inventories.
* **Candidate Directory**: User management with verification badges and attempt histories.

## 🛠️ Tech Stack

| Domain | Technology | Highlights |
|:---|:---|:---|
| **Frontend** | React 18, Vite 8, Tailwind CSS | Sub-second compilation, Lucide icons, html2pdf.js, custom themes |
| **Backend** | Java 17, Spring Boot 3.5 | Spring Security 6, Spring Data JPA, Hibernate, REST APIs |
| **Authentication** | JWT (Stateless Bearer) | Dual-token role isolation (`ROLE_STUDENT` / `ROLE_ADMIN`), BCrypt hashing |
| **Database** | PostgreSQL 15+ / H2 | PostgreSQL (Neon serverless) in production; zero-config H2 for local development |
| **Notifications** | JavaMailSender | Transactional OTP delivery and asynchronous scorecard notifications |
| **Deployment** | Render.com | Automated static SPA hosting and containerized backend web service |

## ⚡ Quick Start

### Prerequisites
* Java 17+
* Node.js 18+ and npm
* Git

### 1. Clone the repository
```bash
git clone https://github.com/Nishantsg3/LearnIQ.git
cd LearnIQ
```

### 2. Start Backend Service
The backend boots in `dev` mode with zero database configuration using embedded H2 in-memory storage and pre-seeds 300 curricular questions:

```bash
cd learniq-backend
APP_JWT_SECRET=your_local_development_jwt_secret_key_32_chars_min ./mvnw spring-boot:run
```
* Service runs at: `http://localhost:8080`
* H2 Database Console: `http://localhost:8080/h2-console`

### 3. Start Frontend Application
In another terminal:

```bash
cd learniq-frontend
npm install
npm run dev
```
* Open [http://localhost:5173](http://localhost:5173) in your browser.
* Use the one-click **Quick Demo Preset** buttons on the login screen to sign in instantly.
